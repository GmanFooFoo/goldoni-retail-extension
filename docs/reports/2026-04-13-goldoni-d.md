## Lessons

1. **Inconsistencies als Qualitäts-Gate.** Der systematische Durchlauf hat gezeigt, dass die v2-Rewrites 8 von 13 Widersprüchen stillschweigend aufgelöst hatten — aber erst die explizite Prüfung macht das sichtbar und dokumentiert. Ohne den Durchlauf wären die "aufgelöst, aber nicht markiert"-Einträge Ballast geblieben.

2. **Content-Layout-Trennung bei Slides.** YAML für Inhalte, Python für Layout — German kann Texte direkt bearbeiten, ohne Code anzufassen. Das ist das gleiche Prinzip wie "Rocket Science jetzt, damit es später einfach wird".
